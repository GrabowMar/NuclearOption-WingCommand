# Gallery images

Drop screenshots/GIFs here with these filenames to slot straight into the main README gallery:

- `tactical-map.png` — tactical map with a wing selected
- `wmc-supply.png` — WMC Supply tab (shop/reserve)
- `formation-flying.png` — a wing holding formation in flight
- `radial-menu.png` — the Wing Command radial menu open

Keep images reasonably sized (1280x720 screenshots, compressed PNG/JPG — a few hundred KB each is plenty). If you use different filenames, update the `src` paths in the "Screenshots" section of the root `README.md`.
