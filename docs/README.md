# Design docs

Shipped design history — the *why* behind decisions that are hard to read back from the
source. Not a roadmap, not a work list. Where a doc and the code disagree, the code wins.

- [ARCHITECTURE.md](ARCHITECTURE.md) — how a player action becomes wingman behaviour.
- [DESIGN_NOTES.md](DESIGN_NOTES.md) — decisions that cost an argument, kept so they aren't relitigated.

Player-facing docs live in the root [README.md](../README.md). Gallery images go in
[images/](images/).
